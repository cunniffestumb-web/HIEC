# HIEC 技术架构说明

## 1. 运行形态

优化版采用“静态页面 + Node.js 服务层”的轻量全栈结构。页面保留原有产品展示、四类教学场景和交互 Demo；服务层负责静态文件、AI 请求代理和协作房间广播。

## 2. 服务模块

- `server.js`：静态文件服务、健康检查、AI 对话接口和 WebSocket 房间服务。
- `POST /api/chat`：默认返回离线演示回答；设置 `HIEC_AI_MODE=deepseek` 后由服务端调用 DeepSeek。
- `GET /api/health`：检查服务是否运行，并返回当前 AI 模式。
- `GET /api/config`：返回不包含密钥的前端服务配置。
- `ws://<host>/ws?room=<room>&name=<name>`：同步讨论消息、操作提示和在线人数。

## 3. 前端模块

- 产品说明页面：展示 Edu-MAS、五层架构、应用场景和发展路线。
- 3D 教学场景：解剖、化学、历史、天文四个场景全部保留。
- 化学协作 Demo：支持本地 3D 分子模型、聊天、操作提示和 WebSocket 广播；连接失败时仍保留本地模拟效果。
- 智能评估：保留本地规则评分原型。

## 4. 安全边界

浏览器不再保存或提交模型密钥。密钥只允许放在服务端 `.env` 中。用户消息、评论、附件名称和协作数据采用 `textContent` 或 DOM 节点渲染，避免把用户输入当作 HTML 执行。

## 5. 已知边界

当前 WebSocket 是轻量演示服务，尚未包含登录、权限、数据库持久化、断线后的历史恢复、CRDT 冲突解决和生产级横向扩展。四类场景是浏览器 Demo，不等同于真实全息硬件或完整学科计算引擎。
