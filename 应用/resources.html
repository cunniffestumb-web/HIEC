快速集成示例

5分钟快速集成HIEC平台的完整示例

// 初始化HIEC客户端
import { HIECClient } from '@hiec/sdk';

const client = new HIECClient({
  apiKey: 'your-api-key',
  endpoint: 'https://api.hiec.com'
});

// 创建3D学习场景
const scene = await client.createScene({
  type: 'holographic',
  subject: 'physics',
  level: 'intermediate'
});

3D内容创建

使用Three.js创建交互式3D教学内容

// 创建3D分子模型
const molecule = new HIEC.Molecule({
  formula: 'H2O',
  interactive: true,
  animation: 'rotation'
});

// 添加到场景
scene.add(molecule);

// 绑定交互事件
molecule.onClick((atom) => {
  showAtomInfo(atom);
});
